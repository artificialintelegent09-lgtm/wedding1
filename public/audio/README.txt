BACKGROUND MUSIC: file required

The invitation is wired to play this file after the guest presses "Buka Undangan":

    public/audio/dunia-yang-nanti.mp3      ("Lagu Dunia Yang Nanti")

The audio is NOT included in the project. Add your own licensed copy at that exact
path (MP3 or AAC, ~128 kbps keeps it around 3-4 MB), or change `music.src` in
src/data/invitations/amelia-rafael.ts to point at another file or format.

Until the file exists the sound button stays hidden and nothing plays.

Rights note: commercial recordings are copyrighted. Make sure you hold the right to use
the song on a public website (or use a licensed / royalty-free track) before deploying.
